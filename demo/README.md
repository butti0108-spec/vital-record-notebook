# デモ用サンプルCSV

このフォルダの `vital-demo-sample.csv` は、**架空のモックデータ**です。実在の方の健康データではありません。

## 使い方

1. バイタル記録ノートを開く
2. 「CSVから戻す」で `vital-demo-sample.csv` を選択
3. 記録・履歴画面の確認や、ポートフォリオ用スクショに利用

## 内容

- 約10日分（朝・夜）
- **体重**が 53.0kg → 51.9kg とほぼ毎日ゆるく下降（戻りなし）
- **血圧**も体重の低下に合わせて、徐々に落ち着く推移
- プロフィール例：生年月日 1950-08-01 / 身長 150cm（架空）
